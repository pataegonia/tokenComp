## Validation monitor 문제

monitor 460349는 기존 `convergence/.monitor_1_A.lock` 때문에 `FileExistsError`로 종료됐다. lock 소유 monitor가 현재 살아 있는지는 다운로드 파일로 확정할 수 없다. 학습 15개는 별도 작업이므로 이 monitor 실패로 중단되지 않았다.

기존 monitor의 실제 실행 상태와 lock 소유를 확인한 뒤 monitor만 복구해야 한다. lock을 무조건 삭제하거나 학습 작업을 재제출할 근거는 없다. 이 로그 확인에서는 서버 파일 삭제·작업 제출·취소를 수행하지 않았다.
